# 剧本适配分析：《歌剧院之夜》

来源：`红之轶事：街头故事_歌剧院之夜.docx`（Tales of the RED，作者 尼尔·布兰金尼奥，译者 瓦里克斯）
提取全文：`rules/red/data/playbook_opera.txt`（25,034 字符，含 6 张 NPC 表）
性质：**街头故事**（短团，约 3–4 小时，4–6 人）

## 一、剧本骨架（作者的场景链）

```
钩引（莱茵迈耶先生的委托：找到露西，每人 2000 EB，先付 500）
 └ 发展（获取门票）            ← 公交站海报、6 个学生闲聊线索
    └ 悬念（歌剧院之夜）        ← 强制遭遇战（小丑+僧侣+吸血鬼三方混战）
       └ 发展（面条和信息）      ← 拉面车接头，拿到"主人"的午夜邀约
          ├ 可选发展（办公室关门时刻）← 撬锁/运动进办公室，3 条可选线索
          └ 悬念（黑暗与光明）    ← "主人"当面委托：去杀鲁思文勋爵
             └ 高潮（怪物狩猎）   ← 门口遭遇（若小丑/僧侣幸存）
                                  ← 教堂内：2 座自动炮塔（网行可接管）
                                  ← Boss：鲁思文勋爵
                                     └ 决议（尾声）← 救出露西、结算报酬
```

## 二、剧本用到的机制（逐条）

| 机制 | 剧本里的用法 | 数值 |
|---|---|---|
| 技能检定 | 觉察 / 撬锁 / 运动 / 犯罪学 / 图书馆检索 / 街头智慧 | DV 9 / 13 |
| 线索发现 | 办公室三处、学生对话、拉面车提前发现吸血鬼 | DV 9 / 13 |
| 社交交涉 | 学生闲聊、雷菲尔德接头、与芭芭拉交换人头 | 无检定（RP） |
| 强制战斗 | 歌剧院三方混战 | 见下 |
| 环境修正 | **前 3 轮所有检定 −4**（尖叫声），配「水平阻尼降噪」免疫 | −4 |
| 敌方战术脚本 | 小丑+僧侣：前 2 轮攻击平摊（玩家/吸血鬼）→ 出现三种情况之一就逃跑（战斗超过 3 轮 / 其中一人重伤 / 任一到达致命伤）→ 跑不掉就用最后行动引爆穿甲手榴弹自杀 | 条件触发 |
| 第三方参战 | 战斗开始时加入「与玩家数量相等」的吸血鬼，目标是小丑/僧侣，被玩家攻击才还手；另：拉面车那场的吸血鬼根本不参战，遇战就用烟雾弹撤 | 条件触发 |

| 网行 | 两个「炮塔控制单元」网络架构（黑冰：渡鸦/地狱犬） | F1–F4 |
| Boss 战 | 鲁思文勋爵：HP 50 / SP 12 / 近战 18 / 闪避 16 / 金刚狼爪 3D6 | 表 6 |
| 战后休整 | 「接受医理并恢复状态」 | 叙事 |
| 奖励 | 500 EB 定金 + 1500 EB 尾款；爱乐吸血鬼的青睐（人情） | 声望/人情 |

## 三、现有引擎覆盖度

图例：✅ 能直接跑 ｜ 🟡 能跑但要手工 ｜ ❌ 引擎做不到

| 剧本要素 | 状态 | 说明 |
|---|---|---|
| 场景文本 + NPC 台词 | ✅ | `story.py` 的 `scenes[].text/npcs`，`npc_flow` 接话 |
| 技能检定 DV 9/13 | ✅ | `card_flow.check`，RED 口径 `≥ DV` |
| 线索（带技能+DV+关键词） | ✅ | `clues.py`，已接 `/线索` |
| 线性场景推进 | ✅ | `gates[]` 的 `next/fail` |
| 分支/可选支线并线 | 🟡 | 只有「成功→A / 失败→B」，没有「可选支线跑完回到主线」；可用两个 gate 拼，但会显得别扭 |
| 强制战斗 | 🟡 | `combat.start_text` 只支持「打手/精英/头目」三种预设，剧本 6 张 NPC 表都要手工塞 |
| 多敌人不同技能/护甲/武器 | ❌ | `EnemyPreset` 只有 name/hp/ref/dex/dodge/skill/sp/damage 八项，没有「多件武器」「技能表」「赛博义眼」 |
| 环境修正（−4 且前 3 轮） | ❌ | 没有「带时限的战斗修正」概念 |
| 敌方脚本行为（逃跑/自杀/换目标） | ❌ | 敌人只有自动射击，没有任何 AI 分支 |
| 第三方阵营参战 | ❌ | 只有 pc/enemy 两方 |
| 自动炮塔 + 网行接管 | ❌ | 无网行，无可交互场景物件 |
| Boss 战（HP50/SP12） | 🟡 | 能建一个「头目」，但 SP 12 与金刚狼爪要手改数据 |
| 奖励结算（EB / 人情） | 🟡 | 有 `growth.award`（IP），没有钱与 Giri/人情记账 |
| 战后医理恢复 | 🟡 | 有 `heal/rest()`，没有「几天休整」的流程命令 |

**结论：叙事层能跑，战斗层差得远。** 以现在的引擎，这个本只能跑到「第一场混战」就开始需要 GM 手工喂骰子——三方混战、限时 −4、敌人逃跑/自爆，一样都表达不出来。

## 四、要补的东西（按优先级）

### P0 · 不做就跑不了
1. **敌方模板库**：`rules/red/data/enemies.json`，直接放这 6 张表（爱乐吸血鬼蠢蛋、小丑、僧侣、审判官和尚、博佐帮蠢蛋、鲁思文勋爵），字段扩到 `hp/wound/sd/sp/ref/dex/cool/will/move/body/emp/skills{}/weapons[]/cyber[]`。
2. **遭遇定义（encounter）**：剧本里写 `"encounter": {"with": "clown+monk", "count": 1, "script": "opera_brawl"}`，开打时自动铺场，而不是玩家手打「开打 精英 2」。
3. **战斗修正规则**：`modifiers: [{scope:"all", value:-4, rounds:"1-3", negate_if:"水平阻尼降噪"}]`。
4. **敌人行为脚本**：最小 DSL 就够——
   `flee_if: {rounds: 3, one_wounded: true, one_critical: true}`、
   `on_flee_fail: {self_destruct: "穿甲手榴弹", damage: "6D6"}`、
   `targets: {rounds:"1-2", split: "pc_or_vampire", after: "vampire"}`。

### P1 · 影响手感
5. **第三阵营**：`side` 从 `pc/enemy` 扩到 `pc/enemy/neutral`，中立方只打 enemy、被打才还手。
6. **场景物件**：掩体已能打（`打木箱`），再加「可交互物件」：炮塔（可被网行接管）、祭坛、开关。
7. **战后休整命令**：`休整 3 天` → 按 BODY 回 HP、清伤势。
8. **钱与 Giri 记账**：角色卡加 `eb` 与 `favors[]`，`结算 +1500eb`。

### P2 · 可选
9. **网行**：炮塔控制单元需要 Netrunning（黑冰/控制节点），这套规则引擎完全没做，需要单独一期（书内页 213 起）。
10. **手榴弹/爆炸物**：书里 10×10 米范围伤害，`multiplier` 与掩体阻挡逻辑已在 `hazards.py` 有雏形。

## 五、建议落地顺序

1. 先做 **P0-1 敌方模板库 + P0-2 遭遇定义**（1.5 天）：能把第一场混战跑起来，玩家不用手写敌人。
2. 再做 **P0-3 修正 + P0-4 行为脚本**（1 天）：这一场的戏剧性全在这两条里。
3. P1 的 5/6/7/8 视需要补。
4. 网行（P2-9）单独排期——不做也能跑完这个本，只是炮塔只能硬打。

## 六、地图需求（对应已完成的 `core/map.py`）

这个本需要 4 张图：
- 交响乐厅（大厅 + 礼堂，观众席可作掩体）
- 夜城大学自助餐厅外广场（开阔，基本无掩体）
- 社会科学大楼四楼走廊 + 办公室（门、办公桌、冰箱）
- 联合教堂（一层 + 地下：长椅区、祭坛、炮塔位）

`map.py` 的格式够用，只差「门」的可开启状态与「炮塔」这类物件属性。
